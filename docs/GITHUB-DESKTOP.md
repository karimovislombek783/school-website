# Upload with GitHub Desktop

1. Extract the project ZIP into a permanent folder such as `Documents/School Website`.
2. Install and sign in to GitHub Desktop.
3. Choose **File → Add local repository** and select the extracted project folder.
4. If the folder is not a repository, choose **Create a repository**. Keep the name, set Git ignore to **None** because `.gitignore` already exists, and do not add a licence yet.
5. Review the file list. `node_modules`, `.next`, `dist`, `.env`, and `.vercel` must not appear.
6. Enter `Initial bilingual school website` and click **Commit to main**.
7. Click **Publish repository**. Keep it private until school leadership approves the content.
8. For future edits, review changes, add a short summary, commit, and click **Push origin**.

Never commit passwords, API keys, student data, private documents, or a completed `.env` file.
